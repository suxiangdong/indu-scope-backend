## 4. 小程序介绍

源仓是一款面向工业品采购与供货企业的微信小程序。平台通过企业认证连接采购方与供货方，支持浏览和发布工业产品、维护产品类目、库存与参数，发布采购需求，以及提交供货响应。

采购方可以在平台浏览认证供货企业的产品，按需求寻找合适的工业品，并发布暂未找到的采购需求；供货方可以完善企业资料，展示产品与供应能力，持续维护产品信息并响应采购需求。源仓以清晰的企业身份、统一的产品信息和可跟进的供需响应，帮助工业企业降低找货与沟通成本，让采购和供货协作更高效。

## 5. 核心功能概述

- 企业认证：支持个人采购方和企业主体按流程提交认证资料，供货方完成企业认证后开展服务。
- 产品展示：按类目展示产品信息、产品图片、库存单位和类目参数。
- 采购需求：采购方发布产品、数量、交期等需求信息，并持续跟进需求状态。
- 供货响应：认证供货企业提交可供数量、交付周期和响应说明，帮助采购方比较供应方案。
- 账号与资料：微信手机号快捷登录，统一管理业务角色、企业资料和认证状态。
